# Primeros Pasos con NUMPY

Este proyecto es una introducción básica a la biblioteca **NumPy** y sus principales funciones.

## Tecnologías utilizadas

- **Python 3**  
- **Jupyter Notebook**  
- **NumPy** – para operaciones con arrays y cálculos matemáticos  


## ¿Cómo empezar?

1. Asegurate de tener instalado Python 3.
2. Cloná este repositorio o descargalo como `.zip`.  

`git clone https://github.com/tatymediina/introducion-numpy`

`cd introducion-numpy`

Crear un entorno virtual (recomendado)
Con venv (Python 3):

`python -m venv env`

Activar el entorno virtual:

En Windows:

`env\Scripts\activate`

En macOS/Linux:

`source venv/bin/activate`

Instalar las dependencias

`pip install -r requirements.txt`

4. Abrí el archivo `.ipynb` en Jupyter. 

5. Ejecutá las celdas
